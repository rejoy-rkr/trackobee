1. Send login / logout events from your website (API)

Works with any website or app, whatever sign-in it uses. When a user signs in or out, your backend makes one call. Trackobee links that user to the PC they are sitting at (by the IP you pass; for an exact link use step 2).

Endpoint

API key

Example:

Call it server-side after a successful sign-in ("event":"login") and on sign-out or session expiry ("event":"logout"). Pass the user's public IP (usually the X-Forwarded-For header). Optional: host (computer name) for an exact link, ts (unix seconds). Form-encoded posts work too. Never put the key in browser code.

2. Exact pairing: website embed (optional)

Add this to pages for signed-in users. It detects the OS, offers the agent install if missing, and links the website user to that exact PC, even when many PCs share one public IP.
